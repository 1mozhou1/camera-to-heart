## 功能概述

前置摄像头 + MediaPipe 手势检测 → 捏合手势驱动粒子从海面飞起聚成蓝宝石爱心。

| 捏合程度 | 效果 |
|----------|------|
| 0~20% | 死区，粒子完全不可见 |
| 20~80% | 粒子分批从海面飞起，向爱心聚拢，螺旋吸入 |
| 80~100% | 爱心完全成形，呼吸心跳 + 光瀑布倾泻入海 |

---

## 渲染管道（back to front）

```
1. 背景渐变 (+ 环境光照)
2. 海底微光 (50 个暖金/暗绿光点)
3. 海面粒子 (2000 个, 2D Gerstner 波面 + 波峰高光)
4. 海面倒影 (爱心下方径向渐变光斑)
5. 光瀑布 (贝塞尔曲线, 辉光+核心双层, 动态数量 8→40)
6. 溅射粒子 (200 个复用池, 光瀑布落海溅起)
7. 爱心粒子 (3000 个: 1200轮廓 + 1600填充 + 200高光)
8. 边光晕 (最外层轮廓粒子半透明光晕)
9. 预览小窗 (右下角 160×120)
```

## 关键参数速查

### 粒子数量

| 名称 | 数量 | 位置 |
|------|------|------|
| SEA_N | 2000 | 海面粒子 |
| HEART_N | 3000 | 爱心粒子（1200轮廓 + 1600填充 + 200高光）|
| FLOW_N | 40 | 光瀑布上限 |
| SPLASH_N | 200 | 溅射粒子池 |
| GLOW_N | 50 | 海底微光 |

### 爱心结构

- **轮廓层**：22 层同心参数曲线 (`heartEq`)，外层→内层缩放 1.0→0.15
- **填充粒子**：随机 t 采样 `heartEq(t)`，向内缩放到 `pow(random, 0.55)`（边缘偏密）
- **高光粒子**：`t ∈ [π*0.42, π*0.88]`（左上 10~11 点钟），scale 0.82~1.0，大而亮

### 手势

| 参数 | 值 | 说明 |
|------|-----|------|
| gamma | 1.6 | `pow(linear, 1.6)` 前期精细后期加速 |
| 死区 | 20% | 捏合 <20% 粒子完全不可见 |
| 弹簧刚度 | 0.3 | 松手回弹速度 |
| 弹簧阻尼 | 0.85 | 回弹衰减（约 0.5s 到位）|
| 校准学习率 | 0.05 | 极值快速学习 |
| 校准回缩率 | 0.001 | 极值缓慢回缩（适应手势变化）|

### 海面

- **波面**：5 层 Gerstner 叠加（x 方向 3 层 + sz 深度方向 2 层）
- **深度分层**：表 45%（亮蓝）、中 35%、深 20%（暗蓝）
- **波峰高光**：`peakBoost = 1 + clamp((surfY - seaTop)/25, -0.3, 0.6)`

### 爱心尺寸

```javascript
heartScale = min(W, H) * 0.011
heartCy = seaTop - 17 * heartScale  // 底部贴着海面
```

## 性能教训（重要！）

### ❌ 会导致卡死

1. **大尺寸离屏 canvas + drawImage** — GPU pipeline stall，即使是 RTX 5060
2. **`drawImage(offscreenCanvas)` 替代 `arc` 画粒子** — 纹理采样开销远超 arc
3. **大量 `.toFixed()` 调用** — 每帧数千次字符串分配

### ✅ 安全做法

1. **直接渲染**到主 canvas，不做离屏中转
2. **`arc + fill`** 画粒子，比 `drawImage` 快
3. **预收集**频繁筛选的子集（如边光晕的 layer=0 粒子）
4. **滞后阈值**避免状态在临界值附近振荡触发重复渲染
5. **钳位物理值**（如 `morphPinch` clamp 到 [0, 1.05]）避免弹簧振荡出界

## 调试技巧

### 显示 FPS

预览窗右下角显示帧率和耗时（当前已关闭）。启用方式：找到这行去掉注释：
```javascript
// previewCtx.fillText(Math.round(currentFPS)+'fps '+frameMs+'ms', pw-6, ph-6);
```

### 临时禁用特效

在渲染管道中找到对应 `// ──` 注释块，整体注释掉即可。

### 检查长帧

在 draw 函数中添加：
```javascript
var t0 = performance.now();
// ... 渲染代码 ...
var dt = performance.now() - t0;
if (dt > 16) console.warn('Long frame:', dt, 'ms');
```

### 爱心形状调试

修改 `heartEq` 函数参数可调整爱心形状。参数方程：
```
x = 12 * sin³(t)
y = -(13*cos(t) - 5*cos(2t) - 2*cos(3t) - cos(4t))
```

### 捏合曲线调试

修改 gamma 值（当前 1.6）：
- gamma > 1：前期精细、后期加速
- gamma < 1：前期灵敏、后期平缓
- gamma = 1：线性

## 修改指南

### 改粒子数

搜索 `SEA_N`、`HEART_N`、`FLOW_N` 等常量，改数字即可。注意：
- `HEART_N` 改了以后，轮廓/填充/高光的比例在 `generateAll()` 中分别设置
- 增加粒子数会影响性能，建议每次 +500 测试

### 改颜色

- **爱心色**：`heartRGB = [55, 160, 240]`（蓝宝石）
- **海面色**：`seaRGB = [50, 150, 215]`（蓝青）
- **高光色**：`cr=210, cg=235, cb=255`（偏白）

### 改动画曲线

- **聚拢速度**：`Math.pow(ep, 1.8)` 中的 1.8
- **起飞速度**：`Math.pow(ep, 1.5)` 中的 1.5
- **光瀑布缓动**：`easeFlow` 函数三段分段曲线

### 改手势

- **死区**：`(p - 0.2)` 中的 0.2
- **Gamma**：`Math.pow(linear, 1.6)` 中的 1.6
- **弹簧**：`SPRING_STIFFNESS` 和 `SPRING_DAMPING`
