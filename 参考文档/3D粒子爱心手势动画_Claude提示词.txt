# 投喂Claude Code 终极细化提示词（粒子海+爱心双重极致细节，手势交互完整）
## 任务目标
生成独立单文件HTML页面，引入TensorFlow.js轻量化手部识别实现摄像头手势捕捉，全屏动态分层粒子海洋背景；五指捏合时在手心坐标生成跟随移动的立体流光粒子爱心，手掌松开后爱心整体崩解，粒子下坠消融进粒子海洋；电脑、手机浏览器直接打开运行，无需本地环境配置。

## 一、全局页面基础
1. 页面全屏铺满，纯深黑底色，隐藏全部滚动条，Canvas画布占满屏幕；
2. 摄像头实时预览框缩小放在画面右下角，透明度0.2半透明，不遮挡粒子特效；
3. 页面加载自动申请摄像头权限，移动端优先调用前置自拍镜头，坐标自动适配横竖屏。

## 二、精细化粒子海洋完整设定（细节拉满）
1. 粒子基础构成
整片屏幕铺满上万颗超细点状粒子，单颗粒子纤细如星尘，基础配色冰蓝+冷银白低饱和微光，单粒自带微弱圆形柔光，不刺眼。
2. 海面起伏波浪动态
粒子存在三维Z轴分层，持续生成多层交错环形涟漪：浪峰粒子上浮、亮度小幅提高，浪谷粒子下沉、透明度降低；波纹随机点位向外缓慢扩散，新旧波纹重叠交织，整片海面匀速缓慢平移流动，无卡顿、无剧烈翻涌，氛围静谧柔和。
3. 景深层次
上层近海面粒子光点清晰明亮；下层远景海面粒子更淡、尺寸更小，营造深海纵深感。
4. 粒子融合规则
爱心尾部滴落流光粒子、松手后崩散下坠粒子落到海面时，不会瞬间消失：逐步缩小光点、降低发光强度，缓慢和海面原生星尘粒子交织融合，最终完全消融汇入波浪，无残留光斑。

## 三、手势识别逻辑
1. 轻量化tfjs手部检测，实时追踪单手掌掌心屏幕坐标；
2. 三种状态判定：
① 五指完全张开：仅渲染粒子海洋，无爱心特效；
② 五指向内聚拢捏合（捏心手势）：掌心坐标生成立体粒子爱心，手掌移动爱心同步跟随位移；
③ 捏合手掌松开、五指张开瞬间：爱心结构破碎，全部粒子受重力下坠融入粒子海。

## 四、极致细化3D粒子爱心完整视觉描述（重点）
1. 整体立体结构
标准饱满立体3D心形轮廓，左右圆弧对称、底部收窄成尖尾，具备真实空间纵深，非平面图案；整体以缓慢恒定速度360°自转，能多角度看清立体轮廓，无生硬边框、无实心填充，整体完全由离散粒子搭建而成。
2. 爱心本体粒子质感
- 构成爱心主体的粒子统一为柔雾粉、蜜桃红渐变发光光点，自带一圈大范围柔和粉色光晕，发光通透朦胧；
- 粒子自带呼吸闪烁动画：亮度周期性明暗渐变，一明一暗缓慢循环；
- 游离动态：少量粒子会短暂飘离心形轮廓一小段距离，随后平缓吸附归位，让爱心灵动不死板；
- 景深区分：靠近镜头一侧爱心粒子更亮、光点更大；背向镜头的粒子透明度降低、光线柔和，强化3D体积感。
3. 底部融化流光尾迹（核心特色）
爱心最下方尖尾位置持续源源不断向外流淌细碎熔融光华粒子，模拟糖果融化、液态星光滴落效果：
- 流光粒子颜色比主体爱心更浅，浅粉+淡白高光，光晕更柔和；
- 流淌粒子从爱心尖尾缓慢向下飘坠，下坠过程持续淡化亮度、缩小体积；
- 未等落到海面就会逐步消散一部分，剩余粒子触碰海面直接融入粒子海洋波纹。
4. 整体光影氛围
爱心悬浮在粒子海面上方，粉色柔光会微弱散射到下方海面粒子，靠近爱心的海面星尘会短暂染上淡粉色反光，氛围感统一。

## 五、爱心崩散坠落完整逻辑（松手触发）
1. 手掌松开瞬间，心形粒子之间的吸附力完全消失，整体结构瞬间破碎；
2. 所有爱心粒子同时拥有向下重力加速度，并向四周各个方向小幅无序散开；
3. 下坠全程持续衰减：光点尺寸不断缩小、粉色光晕逐步褪色变淡；
4. 粒子抵达下层粒子海面层后，完全消融、和冰蓝色海洋粒子混合，彻底消失，不留任何残影。

## 六、性能与代码规范
1. 仅引入tfjs手部识别官方CDN，无重型冗余第三方库，移动端低负载，动画全程流畅；
2. Canvas自适应任意屏幕分辨率，手势坐标自动匹配画布尺寸；
3. 代码内全部可调参数添加中文注释：海面粒子总数、海浪起伏速度、波纹范围、爱心粒子数量、自转速度、流光粒子生成速率、下坠重力、全套粒子配色均可修改。

## 输出强制要求
只输出完整可直接双击打开运行的单HTML文件代码，不附带多余解释、说明文字。
